# K-PII-Bench — Data

Korean PII span-detection benchmark data. **License: CC BY 4.0** (see [`../LICENSE-DATA`](../LICENSE-DATA)).

## Files

| File | Docs | Purpose |
|---|---:|---|
| `train.jsonl` | 243,711 | Training split |
| `dev.jsonl` | 28,147 | Development/validation split |
| `test_track_a.jsonl` | 28,142 | Track A in-domain test (public) |
| `label_map_global.json` | — | BIO label → integer id (37 labels) |
| `split_statistics.json` | — | Per-split domain & skeleton counts |
| `splits/track_b_domains.json` | — | Track B cross-domain membership |
| `splits/track_c/*.jsonl` | — | Track C perturbed test sets (5 perturbations) |

Total: **300,000** documents, **skeleton-disjoint** (0 template overlap across splits).

## Record schema (JSON Lines)

| Field | Type | Description |
|---|---|---|
| `doc_id` | str | Unique document id |
| `template_id` | str | Source template id |
| `domain` | str | One of 12 domains |
| `locale` | str | `ko-KR` |
| `text` | str | Document text (entities rendered, with realistic Korean particle attachment) |
| `template_text` | str | Un-rendered template with `<<TYPE:slot>>` placeholders (the *skeleton*) |
| `entities` | list[obj] | PII spans: `{type, start, end, surface, normalized, placeholder, entity_id, value_id}` (char offsets into `text`, `text[start:end] == surface`) |
| `meta` | obj | `{difficulty, seed, pii_density}` |
| `tokens` | list[str] | KoELECTRA subword tokens (`##` continuation) |
| `bio_tags` | list[str] | Per-token BIO tag |
| `token_offsets` | list[[int,int]] | Char `[start,end)` per token |

Invariant: `len(tokens) == len(bio_tags) == len(token_offsets)`.

## Domains (12)

`support_ticket`, `document`, `education`, `government`, `email_thread`, `medical`,
`telecommunications`, `employment`, `legal`, `chat`, `financial`, `insurance`.

## PII types (18 → 37 BIO labels + `O`)

`PERSON`, `EMAIL_ADDRESS`, `KR_PHONE_NUMBER`, `KR_RRN`, `KR_BANK_ACCOUNT`, `KR_DRIVER_LICENSE`,
`KR_PASSPORT`, `KR_NHIS`, `KR_VEHICLE_PLATE`, `KR_LOCATION`, `CREDIT_CARD`, `IP_ADDRESS`, `URL`,
`USERNAME`, `ORGANIZATION`, `NRP`, `DATE_OF_BIRTH`, `PERSONAL_ATTRIBUTE`.

Each non-`O` type has `B-` and `I-` variants. See `label_map_global.json` for ids.

## Quality (validated)

`scripts/validate_data.py` confirms on this release:

- unreplaced placeholders: **0**
- empty-entity documents: **0**
- span/text mismatches: **0** (`text[start:end] == surface` for every entity)
- token/BIO length misalignments: **0**
- skeleton overlap across splits: **0** (skeleton = `template_text`)

## Privacy

All PII is **synthetic** (generated by the pipeline in `src/k_pii_bench/generation/`). No real
personal data is included. The external KDPII corpus used for additional validation in the paper
is **not** redistributed here.

## Corrected-release note

This is a corrected release. The original generation pipeline located entity offsets by
first-occurrence string search, producing ~35k span/label misalignments (Korean particles
incorrectly absorbed into PII spans) and ~4.2k residual placeholders; a genuine skeleton-disjoint
split was also not present. All were fixed in this release (regenerated text with exact offsets,
repaired placeholders, true skeleton-disjoint split). Manuscript numbers were computed on the
pre-correction snapshot and are tracked separately.
