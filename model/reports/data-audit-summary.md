## 2. 중복 4,035건은 무슨 뜻인가요?

문장 하나가 세 번 등장하면 첫 번째를 제외한 두 번을 ‘추가 등장 2건’으로 셉니다. 따라서 중복 문장 그룹 수와 추가 등장 건수는 서로 다릅니다.

| 분할 | 반복된 서로 다른 문장 그룹 | 첫 등장을 제외한 추가 등장 | 중복 문장 정답 불일치 |
|---|---:|---:|---:|
| `train` | 3,172 | 3,286 | 0 |
| `dev` | 291 | 302 | 0 |
| `test_track_a` | 429 | 447 | 0 |

중복 문장의 정답 종류와 위치를 비교한 결과는 모두 같았습니다. 정답 목록의 순서가 다른 것만으로 불일치라고 판단하지 않았습니다. 정답 문자열의 의미가 옳은지 사람이 판정한 결과는 아닙니다.

**학습·시험 분할 사이의 중복은 0건**입니다. 같은 분할 내부의 반복은 학습 예시나 평가 결과에 특정 문장이 여러 번 반영될 수 있다는 검토 사항입니다. 자동 삭제나 합격 처리는 하지 않았습니다.

후속 작업을 위한 제안이며, 아직 적용하지 않은 처리 방법은 다음과 같습니다.

- 원본 파일과 공식 train/dev/test 분할은 그대로 유지합니다.
- train 5,000건 표본을 고를 때 동일 문장을 한 번만 포함하는 방법을 검토하고, 채택하면 선택 규칙·시드·선택 목록을 기록합니다.
- 공식 평가 결과는 원본 시험 분할 기준을 지킵니다. 중복을 제외한 보조 평가가 필요하면 공식 점수와 별도 항목으로 표시합니다.
- 처리 기준을 확정하기 전에는 이 검사 결과를 `passed`나 학습 준비 완료로 바꾸지 않습니다.

## 3. 평가 자료에 어떤 한계가 있나요?

**개인정보 없는 정상 문장은 모든 분할에서 0건입니다.** 이 데이터만으로 정상 문장 오탐·오차단율을 평가할 수 없습니다. PRD의 별도 서비스 시험셋 300건에 정상 사례 100건 이상을 넣는 준비가 필요합니다.

**`PERSONAL_ATTRIBUTE`는 train에 2,460개 있지만 dev와 test에는 0개입니다.** 이 두 분할만으로 이 유형의 재현율을 확인하거나 임계값을 조정할 수 없습니다. 정답 개수가 0인 지표를 성능 0%나 100%로 해석하지 않고 평가 불가로 표시해야 합니다. 독립 서비스 시험셋에 해당 유형을 포함하는 방안을 검토합니다.

유형별 자료 수 차이도 큽니다. 첫 학습 표본을 단순히 앞에서 5,000건 잘라 사용하는 대신, PRD대로 분야·유형을 고려하는 이유입니다. 이번 단계에서는 학습 표본을 뽑지 않았습니다.
