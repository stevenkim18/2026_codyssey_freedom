## 5. 발표자료 PPT 작성 가이드

### 5.1 기본 규격

- 표지를 제외하고 **10페이지 이내**
- PDF 형식으로 제출
- 초과 분량은 평가에 반영하지 않음
- 디자인, 레이아웃, 페이지 배분은 자유
- 아래 **7개 필수 항목은 반드시 포함**

### 5.2 필수 포함 항목 7개

| 구분 | 필수 항목 | 포함 내용 |
|---|---|---|
| ⓐ | 문제 정의 및 목표 사용자 | 해결하려는 문제, 그 문제를 겪는 대상 |
| ⓑ | 해결 방안 및 주요 기능 | 서비스 개요, 핵심 기능 |
| ⓒ | 활용 AI 기술 및 직접 개발 범위 | 알고리즘, API, 적용 방식 |
| ⓓ | 개발 환경 및 기술 스택 | 언어, 프레임워크, 인프라 |
| ⓔ | 팀원별 역할 분담 | 팀원별 담당 업무 및 기여 내용 |
| ⓕ | 외부 자원 활용 내역 | 아래 표 형식으로 작성 |
| ⓖ | 기대 효과 및 확장 가능성 | 실제 적용 가능성, 추가 개발 방향 |

### 5.3 외부 자원 활용 내역 작성

외부 자원은 아래 형식의 표를 그대로 사용하여 작성해야 함.

| 구분 | 명칭 | 용도 | 라이선스 |
|---|---|---|---|
| 오픈소스 | 예) LangChain 0.3 | RAG 파이프라인 구성 | MIT |
| 외부 API | 예) OpenAI GPT-4o | 텍스트 생성 | 상용 API |
| 사전 보유 코드 | 예) 없음 | | |
| 기타 | 예) Hugging Face | 이미지 분류 | Apache 2.0 |

**작성 유의사항**

- 사전 보유 코드란 개회식 주제 공개 이전에 팀원이 작성했거나 보유한 코드를 의미
- 외부 자원 사용 사실을 누락하고 추후 사용 사실이 확인되면 참가 서약서 위반으로 실격 처리될 수 있음
- 해당 사항이 없는 경우 `해당 없음`으로 기재

### 5.4 PPT 권장 구성

| 페이지 | 내용 | 필수 항목 |
|---|---|---|
| 1 | 문제 정의 및 목표 사용자 | ⓐ |
| 2~3 | 해결 방안 및 주요 기능 | ⓑ |
| 4~5 | 활용 AI 기술 및 직접 개발 범위 | ⓒ |
| 6 | 개발 환경 및 기술 스택 | ⓓ |
| 7 | 팀원별 역할 분담 | ⓔ |
| 8 | 외부 자원 활용 내역 | ⓕ |
| 9~10 | 기대 효과 및 확장 가능성 | ⓖ |

> 필수 항목 7개를 포함한다면 페이지 구성 및 디자인은 자유롭게 조정 가능.

## 7. 결과물(소스코드) 제출 가이드

### 7.1 GitHub 레포지토리

- GitHub 레포지토리를 **Public**으로 설정
- 심사가 끝날 때까지 삭제하거나 비공개로 전환 금지
- 전체 소스코드와 README 포함 필수

### 7.2 README 작성 사항

README에는 다음 실행 방법을 기재해야 함.

1. 설치 방법
2. 환경 설정
3. 실행 명령어

### 7.3 소스코드 URL 제출

GitHub 레포지토리 URL과 최종 커밋 해시를 아래 파일에 작성하여 구글 드라이브에 업로드.

**파일명**

```text
팀명_소스코드.txt
```

**작성 예시**

```text
Repository URL:
https://github.com/organization/project

Final Commit Hash:
abc123456789...
```

### 7.4 주의사항

- 심사는 제출한 최종 커밋 해시를 기준으로 진행
- 마감 이후 커밋은 반영하지 않음
- API 키 등 인증정보는 커밋 금지
- 환경변수 예시 파일인 `.env.example`로 대체
- 레포지토리에 접근할 수 없거나 README가 없는 경우 미제출로 간주

## 8. 심사 방식

### 8.1 심사 개요

총 2단계로 진행됨.

1. **1차 서면 심사:** 전체 참가팀 중 상위 10팀 선발
2. **2차 대면 심사:** 선발된 상위 10팀 대상 발표 심사

심사위원은 외부 AI 전문가 5명으로 구성하며, 1차와 2차 모두 동일한 위원이 평가함.

### 8.2 심사 진행 방식

| 단계 | 일시 | 대상 | 심사 방식 |
|---|---|---|---|
| 1차 서면 심사 | 11월 1일(일) 13:00~17:00 | 전체 팀 | 제출물 기반, 팀당 6분, 100점 만점 |
| 상위 10팀 안내 | 11월 1일(일) 17:00~17:30 | 선발팀 | 개별 안내 및 발표 순서 추첨 |
| 2차 대면 심사 | 11월 2일(월) 13:30~16:45 | 상위 10팀 | 팀당 15분, 100점 만점 |

**1차 서면 심사 — 팀당 6분**

- 시연 영상: 2분
- PPT 확인: 3분
- 채점: 1분

**2차 대면 심사 — 팀당 15분**

- 발표: 7분
- 질의응답(Q&A): 5분
- 심사위원 집계: 3분

발표 7분에는 다음이 포함되어야 함.

- 라이브 시연: **3분 이상**
- 설명: 4분 이내

2. 2차 심사: **아이디어 전달력 및 문제 해결력** 항목 점수가 높은 팀 우선
3. 그래도 동점일 경우 제출 시각이 빠른 팀 우선
