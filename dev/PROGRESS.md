측정 명령:

```sh
cd dev
python -m pytest -q --cov=gateway --cov=detector --cov=launcher --cov-branch \
  --cov-report=term-missing --cov-report=json:.cache/coverage.json
python integration/run_smoke.py
```

커버리지에서 테스트 파일을 제외한다. `gateway/__main__.py`의 2개 실행문은
환경변수를 격리한 별도 Python 프로세스에서 실제 호출·안전 종료를 검증했으나,
해당 자식 프로세스의 실행은 커버리지에 포함되지 않았다. 나머지 미실행 분기는
일부 ASGI 경계·파일 재검증 race 방어·저널 비표준 페이지 크기 거절 등이다.
보안 통제 목표 95% 라인/90% 분기는 제품 기능별로 평가한다.
원격 TLS·실제 모델 정확도·GPU·서버 성능·사용자 환경 전체 설치는 미검증이다.

## 남은 핵심 작업

1. G0: 고정 CLI의 도구 정의·전체 지시문과 16,000자 정책을 함께 만족하는 호환
   설정/버전 검증. 합의 없는 한도 확대·내용 삭제·자체 클라이언트 대체 금지.
2. M0: 공식 자산 리비전·라이브러리 잠금, 전체 구간 추론, 라벨·임계값 A/B 합의,
   GPU 로딩·예열·readiness·모델 교체 실검증.
3. 사건 전송: C 수신 확인 계약 합의, 인증 전송·재시도·중복·장애 후 복구 통합.
4. 운영: 실제 TLS·인증서·설치/롤백·취소/중복·구간별 지연 및 자원 실측.
5. 배포: Ubuntu 24.04-gpu L4 서버와 Ubuntu 24.04-base 일반 서버의 실제 통합.
6. 게시: 등록 gstack 스킬과 허용 소스의 불일치 해결 후 검증한 변경만 `dev`에 푸시.

초기 프로필 검증의 잘못된 기본 OpenAI 경로 요청은 합성 입력·미인증 401이었다.
실제 키나 사용자 입력을 사용하지 않았다. 실패 실행과 수정 후 성공 실행을 분리하며,
상세 경위와 고정 실행 방식은 `README.md`에 기록했다.

이 기록은 첫 정기보고의 검토 가능한 기준이다. 이후 보고 간격은 첫 정기보고 시
