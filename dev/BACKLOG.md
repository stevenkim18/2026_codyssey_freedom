갱신: 2026-10-31 UTC. B 소유 PRD 작업과 개발 중 관찰한 추가 개선 항목을 관리한다.
구현·합성 검증·실제 연동 완료는 별개다. A의 평가·C의 계약을 임의로 확정하지 않는다.

## 완료한 기반과 증거

- R01/R02/R04/R05/R06: 보호 전용 CLI·전체 텍스트 검사·정책·마스킹·출력 버퍼링·
  오류/취소 통제. 실제 CLI의 모의 통합 13개와 사용자 명령 설치→실행→복구 확인.
- M0 `urchade/gliner_multi_pii-v1`: 고정 자산·해시·로컬 패키지, 실제 CPU
  로딩·예열·ASGI 인증/readiness·짧은 검사 2회. 한국어 품질/GPU 완료 주장이 아님.
- 배포: 서버별 계획/사전 확인/배포/검증/롤백, 엄격한 호스트 신뢰·일회성 인증,
  릴리스 파일 해시·프로세스/포트 검증·실패 복귀를 로컬 검증했다.
- HTTPS: 실제 로컬 TLS fixture에서 명시 CA 성공·미신뢰 CA 거절을 확인했다.
- 최신 게시 기준은 [PROGRESS.md](PROGRESS.md), 실행·남은 한계는 각 모듈 README와
  [M0 기록](detector/M0_INTEGRATION_NOTES.md)을 따른다. 저널에는 실제 transaction
  crash 복구 테스트가 이미 있으므로 이를 누락 항목으로 중복 산정하지 않는다.

## 목록 갱신 규칙

새 관찰은 재현 방법·영향·소유 파일·수락 기준을 먼저 기록한다. 재현 가능한 결함은
실패 테스트 → 수정 → 회귀·독립 검증 → 사이클 푸시 순서로 진행한다. 성능 변경은
같은 조건의 기준선과 비교하고 정확도·보안 회귀를 함께 확인한다. 작업 중 발견한
새 위험이나 산정 범위 변화는 채팅과 이 목록에 알린다. 실제 계정·원문·토큰은 쓰지 않는다.
